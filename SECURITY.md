# Security policy

MCPMate gives AI apps access to WordPress sites, so security reports are taken seriously.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's **Report a vulnerability** button on this repository's **Security** tab. Please don't use a public issue.

Include the plugin version, what an attacker could do, and the steps to reproduce it. Leave out real credentials, tokens and site data.

## Supported versions

Only the latest release gets security fixes.
